# etlp - embyToLocalPlayer

Русифицированный форк **etlp** позволяет запускать видео из веб-интерфейса Jellyfin во внешнем локальном проигрывателе с возможностью передачи прогресса просмотра обратно на сервер.  

Основная цель - адаптация оригинального проекта для Jellyfin, русификация интерфейса и конфигурации, а также добавление и изменение некоторых возможностей Tampermonkey-скрипта.

## Отличия от оригинального проекта

В рамках форка внесены следующие изменения:
- Tampermonkey-скрипт переведён на русский язык.
- Добавлены новые настройки и изменено управление функциями через меню Tampermonkey.
- Интеграция с Jellyfin переработана и адаптирована отдельно.
- Конфигурационный INI-файл переведён и адаптирован.
- Код интеграции с Plex полностью удалён.
- Удалены неиспользуемые вызовы GUI и связанные с ними пункты меню.
- Удалены пункты меню, связанные со скрытием сериалов.

- Для замены интерфейсных иконок воспроизведения использована иконка MPC-HC.  

**Python-часть программы не изменялась** и полностью взята из оригинального проекта. Её установка, настройка и принцип работы остались прежними.

### Использование других внешних плееров

В качестве основного внешнего плеера используется [MPC-HC](https://github.com/clsid2/mpc-hc). Добавленные в интерфейс кнопки и значки оформлены с использованием его иконки.

Если вы хотите использовать другой плеер, при необходимости можно заменить Base64-код изображения в Tampermonkey-скрипте на собственную иконку.

Возможность использования других плееров зависит от их совместимости с оригинальной Python-частью и правильности настройки INI-файла. Дополнительное тестирование с другими плеерами не проводилось.

| Настройка                        | Описание                                                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Внешний плеер                    | Включение или отключение использования внешнего проигрывателя                                                        |
| Отображение кнопки в шапке       | Управление отображением дополнительной кнопки в шапке интерфейса                                                     |

## Установка и настройка

### 1. Скачивание и распаковка

Перейдите в раздел [Releases](https://github.com/VitalityV1nT/embyToLocalPlayer-ru/releases) и скачайте архив: `etlp-python-embed-win32.zip`

Распакуйте архив в удобное место (рекомендуется использовать путь без кириллицы и специальных символов).

### 2. Настройка конфигурации

Откройте файл:

`embyToLocalPlayer_config.ini`

Проверьте настройки и при необходимости измените их под свою конфигурацию.

В первую очередь необходимо проверить настройки внешнего проигрывателя и пути к нему.

В разделе сопоставления путей ([src] и [dst]) пути закомментированы. Если планируете использовать режим воспроизведения с жёсткого диска, необходимо указать собственные соответствия. При воспроизведении серверный путь будет заменен на локальный.

Для удобства предусмотрен вспомогательный инструмент настройки.

1. Запустите `embyToLocalPlayer_debug.bat`.
2. Выберите пункт `4` для запуска вспомогательной настройки путей.
3. Используйте предложенный инструмент для получения и сопоставления правильных путей сервера и локального компьютера.
4. Отредактируйте `embyToLocalPlayer_config.ini` в соответствии с полученными путями. 

Если локальное воспроизведение не требуется, этот этап можно пропустить.

### 3. Установка Tampermonkey-скрипта

1. Установите расширение **Tampermonkey** для своего браузера или используйте совместимый аналог (подробнее на странице оригинального проекта).
2. Установите скрипт: [embyToLocalPlayer.user.js](https://raw.githubusercontent.com/VitalityV1nT/embyToLocalPlayer-ru/refs/heads/main/user_script/embyToLocalPlayer.user.js).
3. После установки обновите страницу Jellyfin.

### 4. Проверка работы

1. Запустите `embyToLocalPlayer_debug.bat`.
2. Выберите пункт `1` для запуска в режиме отладки.
3. Не закрывая окно терминала, откройте Jellyfin.
4. Убедитесь что скрипт применился и внешний плеер включен (кнопка в шапке на странице Jellyfin будет включена).
5. Начните воспроизведение и проверьте запуск внешнего проигрывателя, а также передачу прогресса просмотра обратно на сервер (при использовании MPC-HC прогресс отправляется на сервер после закрытия плеера).

### 6. Настройка автоматического запуска

Если тестирование прошло успешно:

1. Снова запустите `embyToLocalPlayer_debug.bat`.
2. Выберите пункт `2` для настройки запуска в фоновом режиме и добавления программы в автозагрузку.

После этого программа будет запускаться автоматически в фоновом режиме.  
Для удаления из автозагрузки в `embyToLocalPlayer_debug.bat` используйте пункт `3` и удалите файл `embyToLocalPlayer.vbs`.

## Linux и macOS

Возможность работы на Linux и macOS теоретически сохраняется, поскольку Python-часть не изменялась. Однако на этих платформах форк не тестировался.

Архив `etlp-python-embed-win32.zip` в релизах данного проекта, предназначен исключительно для Windows.

Пользователям Linux и macOS необходимо самостоятельно скачать оригинальный архив `embyToLocalPlayer.zip` и настроить пути к Python и внешнему проигрывателю.
